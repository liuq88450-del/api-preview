## 本地预览

```bash
cd api-business/site
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

也可以直接双击 `index.html` 用浏览器打开（相对路径正常，无需服务器）。

## 上线前必须替换

1. **销售邮箱**：`trial.html` 里 `SALES_EMAIL = "sales@example.com"`，改成真实邮箱（表单用 mailto 提交，无需后端）。
2. **合规邮箱**：`compliance.html` 第 6 节 `【待补充：合规邮箱】`。
3. **公司主体、备案号**：页脚预留位置。
4. **域名**：页面间用相对路径，换域名不影响。
5. **条款口径复核**：上线前按腾讯书面回复过一遍——数据留存、SLA、可外发资质文件、公开报价是否需报备。

## 内容原则（改稿时守住）

- 不写"公安授权""公安直连""官方数据源"；统一写"经授权的实名核验通道、腾讯云提供准确性证明"。
- 公开页只出现零售资源包；**成本价、渠道价、上游接口细节一律不出现**。
- 示例数据一律脱敏虚构；不出现真实客户数据。
- 不编数字：调用量、SLA、QPS 没有确认值就写"以腾讯云为准""开通时确认"。
