# 三要素实名核验 API · 站点

静态站点，零依赖，可直接部署到任意静态托管（GitHub Pages / 对象存储 / Nginx）。

## 页面

| 文件 | 内容 |
|---|---|
| `index.html` | 首页：能力、价格预览、快速跑通、合规摘要、常见问题 |
| `pricing.html` | 价格：单价、资源包、预存、计费规则 |
| `docs.html` | 接口文档：`POST /v1/id3`、`X-API-Key`、JSON 请求与返回、统一返回码 |
| `quickstart.html` | 快速开始：拿 Key、发请求、看返回码 |
| `failure-reasons.html` | 核验不通过的常见原因：四类原因与自查方法 |
| `compliance.html` | 合规说明：数据处理、授权链条、客户义务、不接受业务 |
| `service.html` | 服务与承诺：资质文件、计费、接入材料、协议、开票、付款、售后 |
| `trust.html` | 信任与资质：主体、备案、数据来源、资质文件、联系方式 |
| `faq.html` | 场景与合规问答 |
| `trial.html` | 申请试用（表单）+ 充值引导 |
| `assets/style.css` | 全站样式，无外部依赖、无字体 CDN，离线可用 |

## 本地预览

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

直接双击 `index.html` 也能看，相对路径正常。

## 改稿时守住的口径

- 只做三要素（姓名 + 身份证号 + 手机号），不涉及人脸、不涉及照片。
- 不写"公安授权""公安直连""官方数据源"；统一写"经授权的实名核验通道"。
- 数据来源只写"合法数据管理机构及其授权方"。
- 不承诺准确率、通过率，只承诺可用性与计费规则。
- 计费口径：完成核验才计费（一致、不一致都算完成）；参数错、Key 无效、限流、额度不足、上游异常都不计费。
- 示例一律虚构脱敏：`110101199003071234`、`13800138000`、`13000000000`，不对应任何真实个人。
- 不出现成本价、渠道价、上游接口细节。
