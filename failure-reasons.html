核验不通过的常见原因

客户投诉里，九成不是"接口坏了"，而是不知道为什么没过。这一页把常见原因、判断方法、给用户的建议讲清楚。

先说口径：我们不承诺准确率，也不承诺通过率。只承诺服务可用和报错不计费；不同数据源覆盖范围不同，同一人在不同时间、不同通道的结果可能不一致。以下为市场常见情况，具体以实际核验结果为准。

先看接口返回了什么

失败时先看三个字段，再决定是不是要找客服：

字段看什么
code大类：NO_MATCH 是"核验完成但不一致"，PARAM_INVALID 是格式问题，QUOTA_EXCEEDED 是余额不足
reason机器可读的原因码，见下表
message给人看的提示，不含用户输入内容
reason含义先查什么

1. 信息本身错

现象

返回 NO_MATCH；用户坚持"我填的就是对的"；换个手机或重新输入后又能过。

怎么判断

  • 身份证号逐位核对，重点看末位 X、数字 0/O、1/I 混淆；
  • 姓名用字：同音字、生僻字、简体/繁体、曾用名；
  • 手机号是否本人实名（运营商 App 可查"一证通查"）；
  • 证件是否在有效期内、是否挂失。

给客户的建议

前端做格式和一致性校验，让用户二次确认；提供"修改后重试"；不要直接封号或判黑，先给用户一次纠正机会。

2. 数据源延迟

现象

刚迁户、刚改名、刚补办证件、刚换手机号，核验不通过；隔几天再试，自动好了。

怎么判断

  • 问用户最近 30 天是否办过户籍、证件、号码变更业务；
  • 同一信息隔 3–7 天复测；
  • 记录首次失败的时间点，便于判断是否"刚变更"。

给客户的建议

业务上给"稍后重试"或"人工复核"入口；这类结果不代表身份造假，别当黑名单处理。市场常见情况，等待时长不确定。

3. 特殊人群

现象

现役军人、武警、特殊部门人员、移民、未换二代证、已故未注销等，可能查无记录或信息不完整。

怎么判断

  • 用户主动说明身份类型（军人证、护照、境外证件）；
  • 证件类型不在居民身份证范围内；
  • 户籍状态特殊（注销、迁出、集体户）。

给客户的建议

转人工或线下材料核验；不要用线上核验作为唯一依据；涉及军人、武警等，按国家相关规定处理。具体名单与规则以主管部门规定为准，本页只作提示。

4. 通道差异

现象

同一个人，今天过、明天不过；或者在不同服务商那里结果不一样。

怎么判断

  • 确认两次输入完全一致（姓名、号码、手机号）；
  • 记录每次的 request_id 和时间，联系我们对比；
  • 区分是"信息变了"还是"通道变了"。

给客户的建议

单次结果不作为最终结论；重要场景加人工复核；把核验当"风险信号"而不是"判决书"。不同数据源覆盖范围不同，这是行业常见情况。

5 步自查

  1. 看 code 和 reason，先排除格式和余额问题；
  2. 核对身份证号、姓名用字、手机号是否本人实名；
  3. 问用户最近有没有迁户、改名、补证、换号；
  4. 同一信息隔 3–7 天复测一次；
  5. 仍不通过，带 request_id + 发生时间 + 脱敏后的输入特征（不要发完整证件号）提工单。

给客服的三句话

先安抚

"核验不通过不等于身份造假，可能是信息没同步或填写有误，我们先帮您核对一下。"

给路径

"如果是刚办或刚改的信息，建议 3–7 天后重试；着急的话我们走人工复核。"

划边界

"特殊证件（军人、护照等）可能不在线上核验范围，需要走线下材料。"
